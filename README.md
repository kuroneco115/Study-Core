# Study Core

ダーク・近未来デザインの学習記録Webアプリです。スマートフォンのブラウザとGitHubだけで公開できます。

## 主な機能

- 今日・直近7日間の学習時間表示
- 教科別の学習時間グラフ
- 学習タイマー（開始・一時停止・リセット）
- 教科、学習内容、時間、問題数、ページ数、正答数・回答数の記録
- 正答率、連続学習日数、経験値（XP）
- 学習履歴の個別削除
- CSV書き出し、JSONバックアップの保存・読み込み
- サンプル問題によるミニ演習
- ブラウザ内保存（APIキー不要、サーバー送信なし）

## スマホからGitHub Pagesで公開する手順

1. GitHubにログインし、`study-core` という名前で新しい **Public repository** を作ります。
2. `Add file` → `Upload files` を開きます。
3. ZIPをスマホで解凍し、**ZIP自体ではなく、中に入っているファイルとフォルダ**をアップロードします。`index.html` がリポジトリの一番上にあることを確認してください。
4. `Commit changes` を押します。
5. リポジトリの `Settings` → `Pages` を開きます。
6. `Build and deployment` の `Source` で `Deploy from a branch` を選びます。
7. Branchを `main`、フォルダを `/(root)` にして `Save` を押します。
8. 数分待ち、同じPages画面に表示される公開URLを開きます。通常は `https://あなたのユーザー名.github.io/study-core/` の形式です。

## ローカルでの確認

`index.html` をブラウザで開いてください。GitHub Pages上ではHTTPSで配信されます。外部ライブラリは使わず、Google Fontsが利用できない環境では端末のフォントにフォールバックします。

## 保存データについて

データは `localStorage` に保存されます。サーバーや別端末との同期はありません。ブラウザデータの消去で記録が消えることがあるため、設定画面からJSONバックアップを定期的に保存してください。

## 現在の制限

- 「全教科対応」は教科分類・記録機能を意味し、全範囲の問題データが内蔵されているわけではありません。
- ミニ演習は学習動作を確認するための少数のサンプル問題です。専門科目・資格試験の正確な問題集は含みません。
- 自由入力に答えるAIチューター、AIによる問題生成、通知、クラウド同期は未実装です。APIキーを使わずに本物の大規模AIを内蔵するものではありません。
- 学習タイマーはブラウザを閉じたり端末がスリープしたりした場合、計測が継続しないことがあります。確実に残すには学習終了後に記録を保存してください。
